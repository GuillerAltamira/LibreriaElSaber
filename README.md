# Sistema de Gestión - Librería "El Saber" (Módulo de Gestión de Productos)

Proyecto desarrollado para la implementación de la capa de acceso a datos y lógica de negocio mediante ASP.NET Core, Entity Framework Core y SQL Server.

## 👥 Integrantes del Grupo
* Grupo Zuñigas

## 🔗 Enlace al Repositorio
* https://github.com/GuillerAltamira/LibreriaElSaber

---

## 📋 Requisitos del Sistema
* *.NET SDK:* Versión 10.0 (o compatible con .NET 8/9/10)
* *IDE:* Visual Studio 2026 (o Visual Studio Code)
* *Gestor de Base de Datos:* SQL Server / SSMS

---

## 🛠️ Tecnologías y Proveedores
* *Framework:* ASP.NET Core Web API
* *ORM:* Entity Framework Core
* *Proveedor de Base de Datos:* Microsoft.EntityFrameworkCore.SqlServer
* *Documentación de Endpoints:* Swagger / OpenAPI
